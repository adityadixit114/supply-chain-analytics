# Enterprise Supply Chain & Inventory Analytics Engine

An end-to-end Python & SQL data processing pipeline engineered to ingest, clean, and analyze enterprise transactional sales, logistics, and inventory datasets.

## Key Capabilities
- **Automated Data Processing**: Cleans and validates 100K+ transactional records across manufacturing & distribution nodes.
- **Stock Anomaly Detection**: Statistical Z-score and IQR-based filtering to detect sudden stockouts and supply bottlenecks.
- **Forecasting & Trends**: 30-day moving average and inventory turnover ratio analytics.
- **Interactive Visualizations**: Power BI and Python dashboards tracking lead times and delivery success rates.

## Setup & Execution
```bash
git clone https://github.com/adityadixit114/supply-chain-analytics.git
cd supply-chain-analytics
pip install -r requirements.txt
python src/analytics_pipeline.py
```
